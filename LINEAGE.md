## Sync Rule

Source changes land in `dovetell-assets` first, then are promoted here after
public-safety review.

When a sample changes:

1. Update the sample files.
2. Update this lineage table.
3. Update the source-side `RELEASE_TARGETS.md`.
4. Update docs links if paths or sample names changed.
