# dovetell sample

Public, cloneable Dovetell samples.

This repo contains public-safe snapshots of Dovetell starter patterns. Use it
when you want to inspect, fork, or adapt a sample without starting from a docs
page.

## Source Boundary

This repo is a public release surface, not the canonical source workshop.

- Source assets and package candidates live in `dovetell-io/dovetell-assets`.
- Public docs and usage guidance live in `dovetell-io/docs`.
- This repo contains reviewed, public-safe sample snapshots.

Do not add private strategy, customer details, credentials, internal launch
notes, or unreconciled roadmap material here.

## How To Use

Clone the repo:

```sh
git clone https://github.com/dovetell-io/sample.git
```

Then copy the sample folder you need into your project and adapt it. Do not copy
sample language blindly; replace it with facts from your repo.
